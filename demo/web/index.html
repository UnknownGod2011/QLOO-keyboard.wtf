Your taste memory lives only in this browser (localStorage). It is sent with each request for that one decision and is not stored on the server. Only short entity names and style words go to Qloo. Sensitive topics (health, religion, politics, sexuality, ethnicity, finances, contact details, immigration, criminal record) are refused.

Same decision engine as the Windows app: Gemini reads the question → taste memory + Qloo Taste AI build an evidence brief → Gemini makes the final, cited decision. Qloo judges cultural affinity, not colour or fit.
