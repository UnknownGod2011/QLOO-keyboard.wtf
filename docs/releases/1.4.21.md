# keyboard.wtf 1.4.21 — prepared release

This is a new package identity; the accepted 1.4.20 installer remains a rollback.
Publication and installed acceptance are separate gates, not implied by this file.

- Adds Luma's optional companion presentation to Settings and the prepared
  website, with accessible pause/hide/mute controls and session cleanup. Luma's
  credentials and voice sessions are separate from Jarvis. Public Voice remains
  unavailable until its protected hosted credential/quota gates pass.
- Checks and provisions the supported Microsoft Visual C++ x64 runtime when
  needed. Microsoft's licence/UAC and a required restart are handled explicitly;
  silent upgrades do not bypass them. No Python, Node or separate .NET setup is
  required for end users.
- The reviewed backend separates conservative Live spending safeguards from
  authoritative customer settlement. Unknown interrupted usage is not guessed
  into a charge; a bounded, audited company-loss policy applies only to newly
  enrolled sessions after its waiting period. Historical holds are not silently
  rewritten. Backend activation remains separately verified.

Existing accepted Jarvis conversation, selected-text translation, screen context,
BA, Smart Writing, routing, saved items and Store Helper 2.1.28 behavior are not
redesigned by these desktop changes. Prices and models are unchanged.

Early launch uses an unsigned Windows installer and manual updates. Fresh-PC/VM
testing was owner-waived; code, package and current-PC checks do not constitute
independent clean-machine proof. Verify the official download/checksum and never
disable protection or bypass malware warnings.
