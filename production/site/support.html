Help with keyboard.wtf

Support

First Windows installation

  1. Download the normal Windows x64 installer from this website. No separate Personal or Paid installer is required.
  2. Review the Windows approval. This early release is unsigned and may show an unknown-publisher or SmartScreen warning; only continue if you trust this exact download.
  3. Complete setup and open keyboard.wtf Settings. Allow microphone access when Windows asks.
  4. Start Google sign-in from the desktop app and approve the one-time pairing in your browser.
  5. Choose Managed usage or Personal API in Settings. Managed uses your account allowance; Personal requires your own compatible API key and does not fall back to Managed charges.
  6. For Chrome page interaction and browser tasks, install the published Chrome Helper and use Check connection. The desktop installer configures its native host; no PowerShell or registry editing is needed.
  7. Use the active shortcuts shown in Settings. If another app owns a preferred shortcut, a fallback can differ from the default. Restart Windows once and check that the same normal app opens.

Browser and Windows download warnings

The current early installer is unsigned and may be unrecognized; that does not mean it is awaiting Microsoft verification. If you have verified and trust the official installer, a browser may offer Keep or Keep anyway. Windows SmartScreen is a separate prompt and may offer More info → Run anyway. These choices are not always available. Stop on a malware warning or an unexpected download, and do not disable browser or Windows protection. Being on this website is not a guarantee that a file is safe.

Sign in and account

Choose Sign in with Google on the Account page. For desktop pairing, begin sign-in from Jarvis, complete Google sign-in in your system browser, and approve that one-time connection. If the request expires, return to Jarvis and start again.

Chrome Helper

Use the published Chrome Web Store Helper 2.1.28 or newer. If you previously tested an unpacked/private Helper, turn it off; do not enable both versions simultaneously. Refresh an ordinary HTTPS tab after installation and use Check connection.

Updates

For this early release, install updates through the normal Windows installer after reviewing the version and source. Unattended/in-app installation is disabled. Do not uninstall first or delete your profile just to update.

Restart or uninstall

Use Restart in Jarvis Settings to safely release hotkeys and reconnect one new instance. Use Delete/Uninstall to launch the registered Windows uninstaller; it asks before removing keyboard.wtf and whether local settings and memories should be preserved.

Billing and devices

Payment status is confirmed by the server from Razorpay evidence and can be delayed briefly. Refresh Account & Billing if needed. Use Devices & sessions to revoke a desktop you no longer use.

Connection or task failure

An interrupted Live connection is not a successful command. Wait for recovery, then ask again if needed; do not repeatedly retry purchases or destructive actions. A failed translation must not claim clipboard success. If a problem persists, share the time, app version and visible error with support without sending API keys or private selected text.
