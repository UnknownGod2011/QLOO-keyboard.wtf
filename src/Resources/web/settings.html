Browser Automation data disclosure

When you start a browser task, the Chrome Helper sends the controlled tab's URL/title, bounded visible page text, selected text, form/control state, and action receipts to the local QLOO app through Chrome Native Messaging. This can include personal information or communications present in the task you selected. When page understanding needs AI, QLOO sends the user request and a bounded task snapshot - plus a current-tab screenshot only for visual recovery - to the configured Gemini browser model.

The extension does not read cookies, password values, OTPs, authentication storage, or file contents. Password, CAPTCHA, file-upload, payment, checkout, banking, and account-security steps stay manual. Data is not sold, used for advertising, creditworthiness, or unrelated profiling. Compact local diagnostic metadata remains until you delete the app log or local app data; page text and screenshots are not written to browser-task history.

Consent is required before the first browser task.

Connectors

Gmail, Calendar and other native connectors use an independently configured QLOO connector relay. Connector sign-in is separate from Gemini inference and does not enable a managed or usage-billed AI backend.

Set both QLOO_CONNECTOR_BACKEND_URL and QLOO_CONNECTOR_WEB_URL before connecting a provider. Without both, Jarvis remains available for local and browser tasks but connector authorization is unavailable.
